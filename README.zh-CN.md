# dropit for Obsidian

[English](./README.md) · **简体中文**

在手机、浏览器、终端里投给 dropit 的东西，实时落进你的 vault。vault 里的东西，右键一下就发到你的其他设备。

dropit 只管送达，之后怎么处理由你决定。想要更多 —— 摘要、打标签、归档 —— 插件可以把每条内容交给你自己选的命令，
它本身不插手（见[运行你自己的命令](#运行你自己的命令)）。

## 一眼看懂

- **收：** 在任何设备上发给 dropit 的东西 —— 文字、链接、照片、视频、文件 —— 都会落进你的 vault，成为笔记，文件嵌在里面。
- **发：** 在 Obsidian 里选中文字 → 右键 →「发到 dropit」；或者在文件列表里右键一篇笔记、几个文件 →「发到 dropit」。
- 手机、浏览器、终端上怎么发，见[每个 dropit 客户端能发什么、怎么发](https://github.com/smart-kits/dropit-client/blob/main/README.zh-CN.md#能发什么怎么发)。

## 功能

- **实时。** 投出去几秒就出现。状态栏一眼可见：**● dropit** 正在实时接收，**○ dropit** 没有。
- **会补齐。** Obsidian 关了两天、笔记本睡眠了？期间投的东西，在打开 Obsidian 或回到窗口时全部补上。没有轮询定时器。
- **一次投递，一篇笔记。** 一起发的文字和文件合成一篇笔记 —— 文字在上，文件嵌在下面。
- **看得懂的文件名。** 按时间和内容命名（`09-29 15.30 下午开会要用的资料.md`）；带网页标题的链接（浏览器扩展会发）显示标题、链接和描述。
- **文件放在你放附件的地方。** 用原文件名，存到「设置 → 文件与链接」指定的附件位置。
- **三种写法。** 每次新建一篇笔记、追加到你指定的一篇笔记末尾、或追加到今天的日记。
- **从 Obsidian 发出去。** 右键选中的文字、一篇笔记或几个文件 → **发到 dropit**。也可以用命令。
- **不丢、也不重复。** 笔记写好之后进度才前进。重新拉取时，vault 里已有的会跳过。
- **不卡住。** 文件下载失败，就在它的位置留一行说明，后面的照常送达；之后重新拉取会把说明换回文件。
- **会自愈。** 服务地址连不上时，自动改用内置地址。
- **桌面和移动端都能用。** 无构建步骤，纯 CommonJS。

## 让 AI 帮你装

用 AI 编程助手（Claude Code、Codex、Cursor……）的话，把这段话贴给它：

```text
按照 https://raw.githubusercontent.com/smart-kits/dropit-obsidian/main/AGENTS.md
把 dropit 插件装进我的 Obsidian vault。装之前先问我是哪个 vault，建账号之前也先问我，
不要显示或提交我的 token。
```

它会找到你的 vault、装好并启用插件，再告诉你配对时具体点哪里。给 AI 的说明在 [AGENTS.md](./AGENTS.md)。

## 安装

还没上架社区插件，先手动装：

```bash
git clone https://github.com/smart-kits/dropit-obsidian.git \
  "<你的 vault>/.obsidian/plugins/dropit"
```

或者把 `main.js`、`manifest.json`、`styles.css` 下载到 `<你的 vault>/.obsidian/plugins/dropit/`。

然后：**设置 → 第三方插件** → 启用 **dropit**。

## 第一次使用

打开 **设置 → dropit**，默认就是「用配对码加入」：

- **已经在用 dropit** → 输入另一台设备上生成的 6 位配对码 → **加入**
- **这是第一台设备** → 「第一次用 dropit？」→ **创建新账号**

之后再加设备：**设置 → dropit → 添加设备 → 生成配对码**。在新设备上输入配对码，或用它的相机扫二维码。
新设备加入时，这个页面会自己刷新。

## 内容写到哪里

在 **设置 → dropit → 收到的内容写到** 里选。

**每次新建一篇笔记**（默认）。每次投递一篇，放在你设置的文件夹里（默认 `Inbox`）：

```markdown
---
kind: batch
source: web
created: 2026-09-29T07:30:00.000Z
dropit_batch: b3k9x0
dropit_seq: [41, 42, 43]
---

下午开会要用的资料

![[预算表.png]]

![[排期.pdf]]
```

单独一条是 `dropit_seq: 42`；`kind` 是 `text`、`url`、`image`、`file`……，几样一起发来的是 `batch`。

**追加到一篇指定笔记。** 每条追加到你指定的笔记末尾（没有会自动创建）：

```markdown
**09-29 15:30** · ios-shortcut
回电话给牙医
```

**追加到今天的日记。** 格式同上，追加到今天日记的末尾 —— 用「日记」核心插件的文件夹、日期格式和模板。
今天的日记还没有时，用那个模板新建；为 Templater 写的模板会交给 Templater 处理。

笔记里不会多出别的东西。插件自己记着追加过哪些，重新拉取时会跳过 —— 包括你事后特意从笔记里删掉的那些。

## 发到 dropit

| 从哪里 | 怎么发 |
|---|---|
| 选中的文字 | 右键 → **发到 dropit**，或命令「dropit: 发送选中的内容」 |
| 一篇笔记 | 在文件列表里右键它 → **发到 dropit**，或命令「dropit: 发送当前笔记」。按文字发；超过 1 MB 的按文件发 |
| 文件 | 右键一个或多选几个 → **发到 dropit**。一次选几个，对方收到的是同一次投递 |

从这个 vault 发出去的东西，不会再写回这个 vault。

## 运行你自己的命令

**设置 → dropit → 收到后运行的命令** 可以选任意一个 Obsidian 命令 —— QuickAdd 宏、Templater 脚本、别的插件的操作。
每条内容**写进 vault 之后**运行一次。

约定：

- **送达从不依赖它。** 先写入，再运行命令，只运行一次，不重试。命令失败不会撤销写入，也不会重发。
- **一次一条。** 按顺序逐条交给命令，间隔一秒。
- **dropit 定格式，脚本归你。** 插件除了写入，不对内容做任何处理。

脚本从 `app.plugins.plugins.dropit.received` 读到当前这条：

```js
{
  v: 1,                      // 格式版本
  seq: 42,                   // 这条的序号，递增
  kind: 'image',             // 'text' · 'url' · 'image' · 'video' · 'file' · …
  source: 'web',             // 从哪里投的
  created: '2026-09-29T07:30:00.000Z',
  batch: { id: 'b3k9x0', index: 2, count: 3 },   // 单独一条时是 null
  text: '',                  // 文字或链接；文件是 ''
  meta: { filename: '预算表.png', mime: 'image/png' },   // 链接还会有 title / description
  note: 'Inbox/09-29 15.30 下午开会要用的资料.md',        // 写到了哪里
  files: ['Inbox/预算表.png'],                  // 为它存进 vault 的文件
}
```

`app.plugins.plugins.dropit.recent` 里是最近 20 条。在别的插件或启动脚本里也可以直接监听 —— 每条都会收到，不用选命令：

```js
app.workspace.on('dropit:received', (item) => { /* 同一个对象 */ });
```

比如一个 QuickAdd 宏的用户脚本：

```js
module.exports = async ({ app }) => {
  const item = app.plugins.plugins.dropit.received;
  if (item.kind !== 'url') return;
  // ……你自己的处理
};
```

> **把内容当作不可信的输入。** 任何拿着你账号「只能投递」token 的人 —— 一台旧手机、一个泄露的快捷指令 ——
> 都能往里放任何东西。不要 `eval` 它，也不要用它拼命令行：通过 **stdin** 或文件交给程序。
> 这个对象是冻结的，一个脚本改不了下一个脚本看到的内容。

## 设置

| 设置 | 作用 |
|---|---|
| *（最上面一行）* | 是否正在实时接收，套餐、设备数和已用空间 —— 以及「立即同步」 |
| 收到的内容写到 · 文件夹 · 笔记 | 内容写到哪里（见上文） |
| 收到后运行的命令 | 你的命令（见上文） |
| 重新拉取 | 重新拉：**全部**、**最近 N 条**、或**最近 N 天**。vault 里已有的跳过；之前下载失败的重新下载 |
| 添加设备 | 给新设备用的配对码和二维码 |
| 设备 | 账号下的所有设备；不用的可以移除 |
| 反馈 | 「反馈问题」在 GitHub 上新开一个 issue，已经填好插件和 Obsidian 的版本；「源代码」打开这个仓库。issue 是公开的，不要贴你的 token |
| 高级 → 服务地址 | 一般不用改。这个地址连不上时，会自动改用内置地址 |
| 高级 → 解除配对 | 只清空本机设置，不会删掉你的内容和其他设备 |

随时手动同步：点状态栏或左侧栏的图标，或运行命令「dropit: 立即同步」。

## 怎么保持连接

- 实时推送走 WebSocket。每 60 秒一次心跳，识别「看起来连着、其实收不到」的死连接（睡眠唤醒后很常见），按 1 秒到 60 秒退避重连。
- 回到 Obsidian 窗口时，如果不能确定连接还活着，就同步一次。
- 当前套餐不含实时推送时（新账号有 14 天体验期），插件提示一次后不再尝试；改为在打开 Obsidian、回到窗口、手动同步时拉取。

## 出问题时

| 状态栏 / 提示 | 含义 | 怎么办 |
|---|---|---|
| `○ dropit · 已断开` | 连接断了，正在重连 | 等一下，或点它立即同步 |
| `⚠ dropit` | 上一次同步失败 —— 鼠标停上去看原因 | 点它重试 |
| `token 无效` / `这台设备已被移除` | token 失效，或这台设备被移除了 | **高级 → 解除配对**，再用新的配对码加入 |
| `设备数已达上限` | 到了套餐的设备上限 | 在「设备」里移除一台不用的 |
| `连不上服务器` | 网络问题 | 检查网络；会自动尝试内置地址 |

详细信息在开发者控制台，前缀 `[dropit]`。

## 隐私

- token 保存在 vault 里这个插件的 `data.json` 中。**如果你同步或公开发布 vault，请排除 `.obsidian/plugins/dropit/data.json`。**
- 解除配对会把它从这台设备上清掉。
