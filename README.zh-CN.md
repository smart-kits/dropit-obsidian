# dropit for Obsidian

[English](./README.md) · **简体中文**

**在手机、浏览器、终端里投的东西，几秒后就成了你 vault 里的笔记 ——
有标题、图片嵌在里面、出处带着链接。反过来，vault 里的任何东西，右键就能发出去。**

桌面端和移动端都能用。它是 [dropit](https://github.com/smart-kits/dropit-client) 的一部分：一条只连着你自己设备的私人管道。

## 用起来是什么感觉

| 你在别处… | 几秒后，vault 里 |
|---|---|
| 在 iPhone 上分享一张照片 | 一篇叫 `10-04 15.30 IMG_2041` 的笔记，照片嵌在里面，存在你的附件文件夹 |
| 在 Chrome 里投一个网页 | `[文章标题](链接)`，作者写的简介作为引用 —— 不是光秃秃一串网址 |
| 在浏览器里选中一段话投过来 | 这段话，下面一行 `— [页面标题](链接)`，永远知道它从哪来 |
| 一次投一段文字加三张截图 | **一篇**笔记：文字在上，三张图在下 |
| 在终端里敲 `dropit send "给银行打电话"` | 一篇写着「给银行打电话」的笔记 |
| 合上笔记本过了个周末 | 一打开 Obsidian，这期间投的全部到齐 —— 不缺一条，也不重复 |

反过来也一样：在文件列表里右键一篇笔记、一个 PDF 或几张图 →「发到 dropit」，手机上就有了。

## 其他设备，以及它们怎么互相找到

这个插件是一个账号里的一台设备；其他设备是同一个账号里的别的 dropit 客户端。按设备挑合适的
（安装页 [dropit.smart-kits.xyz](https://dropit.smart-kits.xyz) 会按你打开它的那台设备推荐一个）：

| 设备 | 客户端 | 能发 | 能收 | 怎么装 |
|---|---|---|---|---|
| **iPhone · iPad** | **dropit** 快捷指令（分享菜单、轻点背面） | ✓ | —（在 Obsidian 手机版里看，或在 Safari 里用网页收件箱） | 用 Safari 打开官网 →「安装快捷指令」 |
| **Android** | dropit App | ✓ | ✓（弹通知） | 官网或 [Releases](https://github.com/smart-kits/dropit-client/releases) 里的 APK |
| **Chrome · Edge** | 扩展 | ✓ | — | 官网「设备」页，或 [代码仓库](https://github.com/smart-kits/dropit-client) |
| **终端**（macOS、Linux） | `dropit` | ✓ | ✓ | 官网「设备」页，或 [代码仓库](https://github.com/smart-kits/dropit-client) |
| **任何浏览器** | 网页收件箱 | ✓ | ✓（点「拉取新内容」） | 不用装：官网本身 |
| **手机上的 Obsidian** | 这个插件，装在手机版里 | ✓ | ✓ | 社区插件，和现在这个一样 |

**怎么把它们加进来：**「设置 → dropit → 添加设备」会显示 6 位配对码和二维码，5 分钟有效。在另一台设备上输入它，或用它的相机扫二维码
（在 iPhone 上会打开快捷指令的设置页，码已经填好）。第一台设备建号，其余的都用这样的码加入。

**一个好用的搭配：** 手机上用快捷指令（iPhone）或 App（Android）发，浏览器里用扩展发，所有东西在这里落成笔记。
想在手机上看这台电脑发出去的东西，把插件也装到 Obsidian 手机版里，或者打开网页收件箱。

## 落在哪里

在「设置 → dropit → 接收 → 笔记写成」里选一次：

| 选项 | 效果 |
|---|---|
| **每次新建一篇笔记**（默认） | 每次投递一篇笔记，放在你指定的文件夹（`Inbox`），按时间和内容命名 |
| **追加到一篇指定笔记** | 全部追加进同一篇笔记（`Inbox/dropit.md`），每条带一行时间 |
| **追加到今天的日记** | 追加到今天的日记 —— 文件夹、日期格式和模板都用「日记」核心插件的设置；Templater 模板交给 Templater 处理 |

文件 —— 图片、视频、PDF —— 存在 Obsidian 放附件的地方（「设置 → 文件与链接」），
按你自己的链接风格嵌进笔记，wikilink 或 Markdown 链接都行。

### 每次新建一篇笔记

```markdown
---
kind: url
source: chrome-extension
created: 2026-10-04T07:30:00.000Z
dropit_seq: 42
---

[How Airmail Worked](https://example.com/airmail)

> A short history of the red-and-blue envelope.
```

文件名是时间加内容：`10-04 15.30 How Airmail Worked`。没有标题的链接变成 `example.com/airmail`，
文字取第一行，文件用它自己的名字。一起投的东西合成一篇 —— 文字在上，文件嵌在下面。

### 追加到一篇指定笔记，或今天的日记

```markdown
**10-04 15:30** · ios-shortcut
![[IMG_2041.jpeg]]

**10-04 15:42** · chrome-extension
一段值得留下的话。

— [页面标题](https://example.com/page)
```

注意：日记指的是内容**写进来那天**的日记。离线几天后补拉到的内容，会写进今天的日记，而不是投递那天的。

## 从 vault 发出去

| 在哪里 | 发出去的是 |
|---|---|
| 在笔记里选中文字 → 右键 →「发到 dropit」 | 选中的文字（整段只是一个链接时按链接发） |
| 在文件列表里右键一个文件 →「发到 dropit」 | 笔记按 Markdown 文字发；其他文件按文件本身发 |
| 选中几个文件 → 右键 →「把这 N 个文件发到 dropit」 | 最多 10 个，对方收到的是一整份 |
| 命令面板：「dropit: 发送当前笔记」·「dropit: 发送选中的内容」 | 同上，用键盘 —— 可以在「设置 → 快捷键」里绑上快捷键 |

笔记按它的文字发出，包括 frontmatter；嵌在里面的图片不会跟着走 —— 想一起发，就在文件列表里把它们也选上。
从这个 vault 发出去的东西，不会再写回这个 vault。

## 状态栏

看一眼就知道状态；点它立即同步。

| 显示 | 意思 |
|---|---|
| `● dropit` | 实时接收中（悬停可以看体验期还剩几天） |
| `◌ dropit` | 正在连接 |
| `↻ dropit` | 正在同步 |
| `○ dropit` | 你的套餐现在没有实时推送：打开或回到 Obsidian 时同步 |
| `○ dropit · 已断开` | 断开了，正在自己重连 |
| `⚠ dropit` | 出了问题 —— 悬停看原因；它会自己重试（大约 5 秒、15 秒，之后每分钟；服务器要求等更久就等更久）。如果这个 vault 已被从账号里移除，就不再重试，等你重新配对或点它手动同步 |
| `dropit · 未配对` | 点它开始设置 |

收到内容时，弹一条提示告诉你收到了几条 —— 点它直接打开最后那篇。

## 不漏一条，也不重复

- **回来就补齐。** 打开 Obsidian 或切回它，这期间到的内容就写进来。
- **网络不稳也扛得住。** 路上被断开的连接（代理、时好时坏的 Wi-Fi）会先重试，同步失败了也会自己再来。
- **一个文件下载不下来，不会堵住后面的。** 它的位置留一行说明：
  `⚠️ report.pdf（820 KB）没能下载下来：……。设置 → dropit → 重新拉取 会再试一次。`
- **重新拉取**（「设置 → dropit → 接收」，最后一行）：全部、最近 N 条，或最近 N 天。vault 里已有的跳过，之前下载失败的重新下载。
  在「每次新建一篇笔记」模式下，你删掉的笔记会被重新生成；另外两种模式下，删掉的就不会回来。
- 新加入的设备只收加入之后投的内容；以前的用「重新拉取」拿回来 —— 能拿回多久，取决于你的套餐保留多久。

## 用 AI agent 或你自己的命令处理收到的内容

「设置 → dropit → 接收 → 收到之后 → AI 自动处理」会把收到的内容交给你电脑上已经装好的命令行 AI agent，或者你自己的命令。
收到的文字或链接会变成**一篇笔记：上面引用发来的原样，下面是处理结果**。

```text
Inbox/10-16 14.02 周四开会.md                  ← 同一篇笔记，处理之后
    > 周四 9 点和供应商开会，带预算表。周五前把报价单发给李工。

    ---

    这是一段待办性质的安排：一个会议和一件待跟进的事。
    - 周四 9 点开会，带预算表
    - 周五前把报价单发给李工
```

- **不打开就不会运行；第一次启用时会先让你看清它要做什么：**会启动哪个程序、完整的参数列表、什么权限，以及
  「**所有符合规则的收到内容都会交给你选的 agent**」。dropit 不经手、不存，也不调用模型、不保存密钥 ——
  agent 用它自己原来的登录状态。
- **命令从一个列表里选一个。**列表里是这台电脑上找到的 Claude Code、Codex CLI、Grok CLI、Gemini CLI、Pi，
  再加「自定义命令…」，写你自己的程序（每行一个参数，不经过 shell）。选一个 dropit 没验证过的 agent，会从它自己的帮助里
  建议的参数开始，当作你自己的命令，可以随便改。
- **四项可勾选。**「图片、PDF」（把文字抽出来）、「语音、视频」（转写）、「链接」（读正文）、「文字」（整理并总结）。勾选会写好**提示词**，
  可以随便改；再勾选时，只有没改过的才会被重写。每条内容调用一次，由 agent 自己判断怎么处理。
- **收到的文字或链接会变成它的处理结果。**front matter 保留，来源页面那一行也保留。不会丢东西：收到的原样就是引用；
  agent 失败的话，笔记保持收到时的样子。打开「保留源文件」，收到的笔记照常保留，结果另存为它旁边的 `<原笔记名> · <规则名>`。
  收到的**文件**总是保留，结果放在它旁边的一篇笔记里。一篇笔记里放着好几条内容（追加笔记、今天的日记、一批一起发的）时，
  这篇笔记从不被替换；每条内容各得一篇，文件名里带上这一条的序号。
- **手动：**「dropit: 用…处理这篇笔记」对打开的笔记运行这条规则（规则关着也能用）；结果总是它旁边的一篇笔记，这篇笔记不会被改动。
  「dropit: 重跑上一条处理」再来一次。
- **试一下、看实际运行什么：**AI 开关旁边的小按钮「试一下」会拿最新一条真的运行一次（会先问你）。命令那一行的「查看…」按钮用一条示例内容，在不运行任何东西的前提下，显示最终命令、会发给 agent 的全部输入和它的环境；
  「对最近一条真跑一次」才真的运行，运行前会确认。
- **失败会在屏幕上说**，一分钟最多一次，所以 agent 找不到时不会刷屏。那篇笔记保持收到时的样子。dropit 不保存运行记录。
- **限制**（默认收起）是你自己的数字：文字最短长度、超时、文字最长、文件最大、积压时处理几条（默认最新 3 条，0 = 全部，其余照常写进库），以及 Claude 的模型名（作为 `--model` 传入，留空用 Claude 自己的默认）。工具本身不设任何限制。文字的限额只管文字：一批一起发的内容里文字比「最长」长、而这批有文件时，文字不交给 agent（agent 会被告知），文件照常处理；「最短」只用于单独一条文字。只有文字的一批被限额挡下时，会弹一条通知说明。

### agent 能用到什么

dropit 按收到的内容分别决定：

| 收到的是 | Claude Code 得到 |
|---|---|
| 文字 | 没有任何工具：读到什么就用文字回答 |
| 链接 | 一个网站：链接指向的那个。链接跳转到别处的不做检查 |
| 图片、视频、文件 | 一个空临时目录里那一个文件的副本，只读，别的都不行 |

目前只验证过 **Claude Code**（2.1.301），所以只有它有这种按内容分别给的权限。它读不了音频和视频，收到时它的回答里会直接说。
要处理它们，用能读的命令。**Codex CLI、Grok CLI、Gemini CLI、Pi** 装了就能被找到、也能选，但 dropit 没有验证过它们的设置能限制到什么程度，
所以它们能做什么由你自己负责。

### 安全

- **收到的内容是不可信的输入。**任何拿着你账号「只能投递」钥匙的人都能把文字放到 agent 面前。所以内容只会发到 agent 的
  **标准输入**，放在标明是数据的块里，绝不放进命令行，也不放进你写的指令；处理文字时 Claude Code **没有任何工具**。
- **agent 在一个空的临时目录里启动**，环境变量只有 `PATH`、`HOME`、`USER`，有超时，不重试；运行完目录就删掉。
- **回答写成文件之前先清洗：**远程图片和嵌入、HTML、代码块标注的语言（标给查询或脚本插件的代码块会被执行）、
  模板和查询语法，都会被处理掉。引用的原文照收到的样子写入（Templater 在运行新笔记时，`<%` 会像对任何收到的笔记一样被拆开）。
- **失败不会挡住内容送达。**先写入内容，再处理。
- 你写的提示词里，只有 `{{kind}}` 这一个变量有意义：其它变量会被丢弃，因为标题、文件名和正文都是发送者写的。

**仅桌面版。**手机上这一节的设置只显示一句说明，不会启动任何程序；接收照常。

### 不限制 agent

默认情况下，Claude Code 只拿到每条内容所需要的东西。如果你想要一个能做更多事的 agent（打开要登录的页面、用密钥读不公开的链接、调用技能或 MCP 服务、处理视频），勾上四个框旁边的**不限制 agent**。勾的时候会问一次，警告写得完整。

打开后，dropit 什么都不加、什么都不拿走：它启动的是 `claude -p --no-session-persistence`（*命令*那一行会显示）。Claude Code 按**你自己的设置**运行（技能、MCP 服务、hooks、指令、允许和拒绝规则），并带着**你的全部环境变量**。内容的文件照旧复制进工作文件夹。取消勾选就回到默认。

- **这是对安全影响最大的设置。** 收到的内容仍然不可信，持有你账号「只投递」密钥的人，可以把内容送到 agent 面前。不限制之后，这些内容能间接指挥一个拥有你自己全部权限的 agent，而且没有人在场确认。不再用的设备请移除，Claude Code 设置里的权限也请按这件事需要的程度收紧。
- **权限归你。** 运行是无人值守的，没有谁能被询问：需要批准的操作，除非你的 Claude Code 设置已经允许，否则会被拒绝。要让它做某件事，去那里允许。
- **要加限制：** 在 Claude Code 设置里写允许和拒绝规则，或者改*命令*那一行，把能用的东西点名，例如
  `claude -p --permission-mode dontAsk --allowedTools WebFetch --disallowedTools Bash`
  （见 `claude --help`：`--allowedTools`、`--disallowedTools`、`--permission-mode`、`--add-dir`）。改过的命令按原样运行，只拿到 `PATH`、`HOME`、`USER`，它要用的密钥请放进你的脚本或钥匙串。
- **技能、工具、MCP 服务：** 在 Claude Code 里自己配置；不限制时它们会被加载，提示词里可以点名让它用。*显示…* 会列出命令，以及它会拿到的环境变量的名字（不显示值）。
- 从 Dock 或开始菜单启动的 Obsidian，可能看不到你在 shell 配置里设的变量。agent 需要的话，放进 Claude Code 自己的设置，或写进一个设好它的脚本。

**读视频里说了什么**（抖音、TikTok、B 站……）有一份分步的[指南](https://github.com/smart-kits/dropit-client/blob/main/docs/ai-videos.zh-CN.md)：要装的工具、一个小脚本、要放行什么，以及测过什么、没测什么。

有人会这样搭。下面都是你自己的搭法，不是 dropit 的功能，dropit 也没有验证过：

- *视频、音频：* 把你自己的脚本（比如下载器加语音转文字工具）当作自定义命令。
- *要登录的页面：* 一个驱动浏览器、带自己保存的登录状态的 MCP 服务，在提示词里让它去用。
- *不公开的链接：* 密钥放在你的脚本或钥匙串里，由命令带上。

## 每收到一条，运行你自己的命令

「设置 → dropit → 接收 → 收到之后 → 运行 Obsidian 命令」可以选任意一个 Obsidian 命令 —— QuickAdd 宏、Templater 脚本、
别的插件的动作。每一条内容写进 vault **之后**，它运行一次。
（想把内容交给 AI agent，不需要用这个：见上面的「用你的 AI agent 处理收到的内容」。两者可以一起用。）

- **送达从不依赖它。** 先写入，再运行，只运行一次，不重试。
- **一次一条**，间隔一秒。
- **格式由 dropit 定，脚本归你。** 插件对内容除了写进去，什么都不做。

你的脚本从 `app.plugins.plugins.dropit.received` 读当前这一条：

```js
{
  v: 1,                      // 格式版本
  seq: 42,                   // 这一条的序号，递增
  kind: 'image',             // 'text' · 'url' · 'image' · 'video' · 'file' · …
  source: 'web',             // 从哪里投的
  created: '2026-09-29T07:30:00.000Z',
  batch: { id: 'b3k9x0', index: 2, count: 3 },   // 单独投的为 null
  text: '',                  // 文字或链接；文件为 ''
  meta: { filename: 'budget.png', mime: 'image/png' },   // 链接还有 title / description；
                             // from: { url, title? }，投递时所在的页面（浏览器扩展）
  note: 'Inbox/09-29 15.30 Slides for the 3pm meeting.md',   // 写到了哪篇
  files: ['Inbox/budget.png'],                   // 为它存进 vault 的文件
}
```

`app.plugins.plugins.dropit.recent` 保存最近 20 条。在别的插件或启动脚本里，也可以直接监听 ——
每一条都会触发，不用设置命令：

```js
app.workspace.on('dropit:received', (item) => { /* 同一个对象 */ });
```

比如一个 QuickAdd 宏的用户脚本：

```js
module.exports = async ({ app }) => {
  const item = app.plugins.plugins.dropit.received;
  if (item.kind !== 'url') return;
  // ……你自己的处理
};
```

> **把内容当作不可信的输入。** 任何拿着你账号「只能投递」钥匙的东西 —— 一部旧手机、一个泄露的快捷指令 ——
> 都能往里放任何内容。别 `eval` 它，也永远别用它拼 shell 命令行：通过 **stdin** 或文件交给程序。
> 这个对象是冻结的，一个脚本改不了下一个脚本看到的内容。

## 装好它

1. **安装。** 「设置 → 第三方插件 → 浏览」，搜索 **dropit**，点「安装」。也可以从 [dropit.smart-kits.xyz](https://dropit.smart-kits.xyz) 下载，
   解压到 `<你的 vault>/.obsidian/plugins/`；或者直接 clone 到那里：

   ```bash
   git clone https://github.com/smart-kits/dropit-obsidian.git "<你的 vault>/.obsidian/plugins/dropit"
   ```

   然后「设置 → 第三方插件」→ 启用 **dropit**。
2. **加入。** 「设置 → dropit」打开就是「用配对码加入」。在一台已经在用的设备上调出配对码
   （网页收件箱的「设备」页；终端里 `dropit code`），输入这 6 位，点「加入」。
   这是你的第一台设备？「第一次用 dropit？→ 创建新账号」。
3. **其他设备从这里加。** 「设置 → dropit → 添加设备 → 生成配对码」：在新设备上输入，
   或者用它的相机扫二维码。配对码已经帮你复制好了，新设备加入后页面会自己发现。

用 AI 编程助手（Claude Code、Codex、Cursor……）？把下面这段贴给它，它会帮你装好：

Install the dropit plugin into my Obsidian vault by following
https://raw.githubusercontent.com/smart-kits/dropit-obsidian/main/AGENTS.md
Ask me which vault and before creating an account, and never show or commit my token.

## 出问题时

| 你看到 | 意思是 | 怎么办 |
|---|---|---|
| `⚠ dropit` ·「连不上服务器」 | 网络或代理在断连接 | 一般不用管 —— 它会重试。一直这样的话，检查代理，或者让它直连 dropit |
| 「token 无效」·「这台设备已被移除」 | 这个 vault 被从账号里移除了 | 用新的配对码重新加入 |
| 「设备数已达上限」 | 套餐的设备名额用完了 | 移除一台不用的设备（「设置 → dropit → 设备」） |
| 「配对码已过期」 | 配对码 5 分钟有效，只能用一次 | 重新生成一个 |
| 「实时推送体验已结束」 | 新账号有一段实时推送体验期；之后改为打开或回到 Obsidian 时同步 | 不用修 —— 随时点状态栏就能同步 |
| 笔记里出现 `⚠️ ……没能下载下来` | 这次文件没下下来 | 「设置 → dropit → 重新拉取」 |

其他问题：「设置 → dropit」最底部的「反馈问题」链接（公开的 issue）。账号相关、不方便公开的问题，发邮件到 [support@dropit.smart-kits.xyz](mailto:support@dropit.smart-kits.xyz)。

## 隐私

- 登录信息存在 vault 里这个插件的 `data.json` 中。**如果你同步或公开 vault，请排除
  `.obsidian/plugins/dropit/data.json`。** 「解除配对」会清掉它。
  vault 同步时如果把 `data.json` 一起带过去（开了「第三方插件设置」的 Obsidian 同步、iCloud、Syncthing、Git），
  每一份都会以同一台设备的身份接收，同一条内容可能每一份各写一次。让其中一份负责接收：把 `data.json` 排除在同步之外。
- 来自别的设备和网页的文字不会被当成代码执行。如果 Templater 设置了新建笔记时当模板运行（*Trigger Templater on new file creation*），
  收到内容里的 `<%` 会在 `<` 后面加一个看不见的零宽空格写入，Templater 就不会把它当成命令。看起来一样；交给你命令的 payload 保留原文。
- 自动处理在你打开之前不会运行。打开之后，收到的、符合规则的内容会交给你选的 agent，在你自己的电脑上处理；dropit 不保存它，
  也不保存运行记录。规则存在这个插件的 `data.json` 里，和登录信息放在一起，不与命令行工具共用。
- 每台设备有自己的钥匙，可以单独移除；移除后名额立刻释放。
- 这个 vault 重新配对（比如重装插件之后）会替换之前那次配对，不再多占名额。为了认出来，插件会带上它原来的钥匙（如果还有），
  以及一个随机 ID 的 SHA-256 摘要。这个 ID 在这个 vault 第一次加入 dropit 时生成，存在 Obsidian 为这台设备上这个 vault 单独保留的本地存储里 ——
  不在 `data.json` 里，也不随 vault 同步 —— 所以重装插件后还在。它不含你电脑或手机的任何信息，离开设备的只有摘要，它也不是登录凭证。
- 插件只连一个服务：dropit 服务器，用来发送和接收你的内容。它存了什么、存多久、谁能看到：[隐私说明](https://dropit.smart-kits.xyz/privacy)。
